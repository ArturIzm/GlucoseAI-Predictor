# GlucoseAI Predictor

Проект **GlucoseAI Predictor** направлен на прогнозирование уровня сахара в крови у людей с диабетом с использованием моделей глубокого обучения, таких как LSTM. Основная цель — улучшить точность предсказаний за счёт добавления новых признаков, включая статистические характеристики временного ряда и физиологическую модель.

## Описание проекта

Этот проект исследует возможности улучшения предсказаний уровня глюкозы в крови с помощью:
- **LSTM-моделей** для анализа временных рядов.
- **Дополнительных признаков**, таких как:
  - Лаговые признаки (lag features).
  - Скользящее среднее и стандартное отклонение.
  - Признаки, основанные на физиологической модели Hovorka.
- **Статистические характеристики**, такие как максимумы, минимумы и разности.

## Используемые технологии

- **Python**: Основной язык разработки.
- **PyTorch**: Для реализации и обучения LSTM-моделей.
- **NumPy, Pandas**: Для обработки данных.
- **Matplotlib**: Для визуализации результатов.
- **Scikit-learn**: Для расчёта метрик и масштабирования данных.
- **Weights & Biases (wandb)**: Для отслеживания экспериментов и сравнения моделей.

№№ Результаты

Добавление признаков Hovorka и статистических характеристик улучшило точность предсказаний.
Исследование показало, что дополнительные признаки позволяют использовать более простые модели (с меньшим количеством параметров) для достижения того же уровня качества предсказаний, что и более сложные модели без этих признаков.
Использование wandb помогло эффективно сравнить модели и визуализировать их метрики (MSE, R2, MAPE).
